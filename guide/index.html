INSTALLATION GUIDE

세 단계로
간단하게 시작하세요.

설치가 끝나면 바탕화면 또는 시작 메뉴에서 인피퐁 매니저를 실행할 수 있습니다.

01

설치 파일 받기

공식 다운로드 페이지에서 최신 Windows 설치 파일을 내려받습니다.

다운로드 페이지 →
02

설치 진행하기

내려받은 Inpiong-Manager-Setup-x64.exe를 실행하고 화면 안내에 따라 설치합니다.

03

기존 계정으로 로그인

웹에서 사용하던 계정으로 로그인하면 같은 회원·레슨·대회 운영 데이터가 연결됩니다.

Windows 보호 안내가 보이는 경우

현재 공개 버전은 코드 서명 인증서 적용 전이라 SmartScreen 안내가 나타날 수 있습니다. 파일명이 정확하고 공식 다운로드 페이지에서 받은 파일인지 먼저 확인하세요.

업데이트 방법

새 버전이 공개되면 기존 프로그램을 삭제하지 않고 최신 설치 파일을 다시 실행하면 됩니다. 운영 데이터는 Firebase 계정과 연동되므로 프로그램을 업데이트해도 삭제되지 않습니다.
