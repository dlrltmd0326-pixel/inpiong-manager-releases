FREQUENTLY ASKED QUESTIONS

궁금한 내용을
빠르게 확인하세요.

PC 프로그램과 웹의 자료가 같이 보이나요?

네. 동일한 계정으로 로그인하면 권한에 맞는 회원·레슨·일반손님·대회 운영 데이터가 연결됩니다.

인터넷이 잠깐 끊기면 어떻게 되나요?

PC 프로그램은 연결 상태와 저장 상태를 표시하고, 지원되는 작업은 로컬에 임시 보관한 뒤 연결이 복구되면 동기화합니다.

Windows에서 보호 안내가 나오는 이유는 무엇인가요?

현재 설치 파일에 유료 코드 서명 인증서가 아직 적용되지 않았기 때문입니다. 공식 다운로드 페이지의 파일명과 SHA-256을 확인해 주세요.

새 버전은 어떻게 설치하나요?

최신 설치 파일을 다시 내려받아 실행하면 됩니다. 기존 운영 데이터는 계정에 연결되어 유지됩니다.

모바일이나 태블릿에서도 사용할 수 있나요?

운영 웹은 모바일과 태블릿 화면에 맞춰 사용할 수 있고, Android 앱도 같은 운영 데이터를 사용합니다.

설치 파일이 최신 버전인지 어떻게 확인하나요?

공식 다운로드 페이지에 표시된 버전과 GitHub 최신 릴리스 페이지를 확인하면 됩니다.
